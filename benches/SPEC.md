## §C CONSTRAINTS

- harness chosen by T1 w/ §R row (`criterion` vs `divan`: statistics, baselines, run time on push).
- fixtures generated by seeded generator: sizes 1k · 10k · 100k · 1M observations; partitions 1 · 4 · 52 · 520; deterministic from seed ∴ reproducible.
- suites: hook write (cold process, `chert hook run`) · injecting `session-start` · opt-in injecting `user-prompt-submit` (cost behind `inject.on_prompt` disclaimer) · `get_observations` · recent-window search (cache warm & cold) · cross-partition search · semantic re-rank · cache warm-up · partition scan · compress & expand.
- baseline `benches/baseline.toml`: per suite & size: median, p95, machine, date, recount command. updated only by own reviewed commit.
- regression = median > baseline × (1 + tolerance) on same machine class; tolerance per suite in baseline.

## §I INTERFACES

- cmd: `cargo bench -p chertmem`; `cargo run -p dev -- bench-gate` compares to baseline.
- file: `benches/baseline.toml`.
- target (as built, wave 9): `[[bench]] latency` = `benches/latency/main.rs`, `harness = false`; `[[bench]] latency-tests` = same modules via `lib.rs` under libtest, `test = true`, `bench = false` ∴ nextest runs V1, V2. bench id `<suite>/<size>-p<parts>` (`1k-p52`); filter: `cargo bench -p chertmem -- '/100k-p'`. criterion output `target/criterion/<suite>/<label>/new/estimates.json`.
- dir: `target/bench-fixtures/<seed>-<size>-<parts>/` (`project/`, `data/`, `stamp` = generator version, key, digest); stale stamp → rebuilt.
